# Examples

Every bundled example can be written to disk:

```bash
lumen --examples <name>
```

| Name | File written | Topic |
|---|---|---|
| `age` | `age.lmn` | variables, input, arithmetic |
| `fizzbuzz` | `fizzbuzz.lmn` | `repeat`, `if`/`elif`/`else`, `%` |
| `temperature` | `temperature.lmn` | functions, routines, branching |
| `infinite-loop` | `infinite.lmn` | labels and jumps |

Each example is broken down in its own page, in increasing order of the language features it touches. The example pages also carry a QR next to the source that can be scanned into [Lumen on Android](../lumen-in-apps/lumen-on-android.md).
